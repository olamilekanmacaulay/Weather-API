# Weather-API
Build a weather API that fetches and returns weather data.

Project URL: https://roadmap.sh/projects/weather-api-wrapper-service

In this project, instead of relying on my own weather data, I built a weather API that fetches and returns weather data from a third-party API. 

Visual Crossing’s weather API was used.

Regarding the in-memory cache, the city code entered by the user is used as the key.
